## 💻 Local Development

### Prerequisites
- Node.js 18.x or 20.x+
- npm / pnpm / yarn

### Quick Start

```bash
# 1. Clone the repository
git clone https://github.com/nleelaranga-ai/ranga_portfolio.git
cd ranga_portfolio

# 2. Install dependencies
npm install

# 3. Start local development server
npm run dev
```

Visit `http://localhost:3000` in your browser.
